# AGENTS.md

This branch, `warpdotdev-factory`, is one of several software-factory
experiments in this repo. Each experiment lives on its own branch cut from
`main`. This one installs Warp's own factory tooling:

- the Factory definition in `warp-factory/`;
- Warp's public skill packs;
- workflows and MCP config.

Everything is set up for the Warp Free plan with the user's own Anthropic key.

## Layout

| Path | What it is |
|---|---|
| `warp-factory/` | Warp Factory as code (agents, automations, runners, scorers, skills). See its README. |
| `.agents/skills/` | Skills Warp loads. Vendored ones are symlinks, generated by the script below. `factory-local/` is ours. |
| `.agents/shared` | Symlink to scripts that the oz-for-oss skills run. |
| `vendor/warp-skills/<source>/` | Warp skill packs copied verbatim. `skills.toml` records repo, commit, license and which skills are off. |
| `vendor/warp-drive/do-things/` | Index cards for Warp Drive objects, imported by hand (see `IMPORT.md`). |
| `.warp/workflows/` | Workflow palette entries (Ctrl+Shift+R). |
| `.warp/.mcp.json` | Project MCP servers. |
| `warp/` | Machine-level templates that `scripts/warp-setup.sh` installs. |
| `scripts/` | `warp-skills.py` (skill packs) and `warp-setup.sh` (machine setup). |
| `tools/warp/` | Warp's factory validator. |

## Rules

- Do not edit anything under `vendor/` by hand. Update a pack with
  `python3 scripts/warp-skills.py update <source>`, then review the diff.
- Turn skills on or off only with `python3 scripts/warp-skills.py enable|disable <skill>`.
  Never add or delete symlinks in `.agents/skills` yourself.
- Change `warp-factory/agents/*/agent.md` prompts only when the user asks.
- Keep every automation in `warp-factory/automations/` at `enabled: false`
  unless the user asks to enable one.
- Do work for a change on a `factory/<id>` branch in `.worktrees/<id>/`.
- Never merge. Never push to `main`, `staging`, `warpdotdev-factory` or another
  experiment's branch. Pull requests are drafts, and a human merges them.
- Do not run scripts from a freshly downloaded repo. Copy the files, read them,
  and only then use them.

## Checks

Run the checks that cover what you changed, and report the command and result:

```bash
python3 -I tools/warp/validate_factory_files.py warp-factory   # exit 2 = not checked
python3 scripts/warp-skills.py check
bash -n scripts/warp-setup.sh
```
